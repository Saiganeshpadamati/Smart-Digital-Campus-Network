Architecture Evolution

Problem & Solution Matrix

How our redesigned architecture resolves legacy campus infrastructure bottlenecks, security vulnerabilities, and single points of failure.

Legacy Campus Problem Underlying Root Cause Our Engineering Fix
Slow Internet & Congestion
Single flat /16 network with uncontrolled broadcast domains, ARP storm flooding, and lack of bandwidth allocation for academic services.
Segmented 802.1Q VLANs + Dedicated Student /20 Subnet

Isolated broadcast domains, rate limiting, and prioritized QoS for critical ERP & Exam traffic.

Unauthorized Admin & Exam Access
Unrestricted inter-subnet routing allowed any connected student laptop to probe finance servers, ERP databases, and test question banks.
Strict Zero-Trust ACLs & Air-Gapped Exam Zone

VLAN 50 (Exam) locked strictly to 10.70.0.12 with zero WAN access; Student VLAN blocked from Admin VLAN 20.

Frequent Campus-Wide Outages
Single core switch with no redundancy. Hardware reboots or fiber cuts immediately severed all campus operations.
Dual-Core HSRP/VRRP & OSPF Multi-Area Redundancy

Active-Active dual core routers (Core1 & Core2) with virtual .1 gateways and sub-1.5s automatic failover.

IoT & Camera Cyberattacks
Unsecured IoT smart devices and IP cameras connected directly to the open campus LAN, exposing them to Mirai botnet infections.
Isolated IoT / CCTV VLANs + AI Threat Telemetry

VLAN 60 cameras blocked from WAN; AI telemetry detects volumetric floods and port scans instantly.

Zero-Trust Policies

Security Rules & Access Control Lists (ACLs)

Granular Layer 3/4 traffic filtering policies enforcing principle of least privilege across academic, student, and server zones.

Student Wi-Fi (VLAN 30)

Restricted
  • Permitted: HTTP (80) & HTTPS (443) to Server VLAN (10.70.0.0/24)
  • Permitted: ICMP Ping to Server VLAN
  • Permitted: Full Public Internet Access (NAT)
  • Denied: All internal subnets (VLAN 10, 20, 40, 50, 60)
ip access-list extended ACL-STUDENT-IN permit tcp 10.30.0.0 0.0.15.255 10.70.0.0 0.0.0.255 eq 80 443 permit icmp 10.30.0.0 0.0.15.255 10.70.0.0 0.0.0.255 deny ip 10.30.0.0 0.0.15.255 10.0.0.0 0.255.255.255 permit ip 10.30.0.0 0.0.15.255 any

IoT Labs (VLAN 40)

Port-Locked
  • Permitted: HTTPS (443) to Server VLAN
  • Permitted: MQTT over TLS (8883) to Server VLAN
  • Permitted: Outbound Internet for cloud telemetry
  • Denied: Student, Admin, and Exam subnets
ip access-list extended ACL-IOT-IN permit tcp 10.40.0.0 0.0.0.255 10.70.0.0 0.0.0.255 eq 443 8883 deny ip 10.40.0.0 0.0.0.255 10.0.0.0 0.255.255.255 permit ip 10.40.0.0 0.0.0.255 any

Online Exam (VLAN 50)

Zero Internet
  • Permitted: HTTPS (443) ONLY to Exam Server (10.70.0.12)
  • STRICTLY BLOCKED: Public Internet (WAN Dropped)
  • STRICTLY BLOCKED: All other servers and VLANs
  • Anti-Cheat Layer: Prevents external communication
ip access-list extended ACL-EXAM-IN permit tcp 10.50.0.0 0.0.0.255 host 10.70.0.12 eq 443 deny ip any any

CCTV / AI (VLAN 60)

Air-Gapped
  • Permitted: Video Stream (RTSP 554/HTTP) to Server VLAN
  • Permitted: AI Analytics NVR Node (10.70.0.15)
  • STRICTLY BLOCKED: Public Internet (No WAN access)
  • Eliminates camera botnet hijacking vectors
ip access-list extended ACL-CCTV-IN permit ip 10.60.0.0 0.0.0.255 10.70.0.0 0.0.0.255 deny ip any any

Admin / ERP (VLAN 20)

Full Management
  • Permitted: Full administrative access to ERP Database (10.70.0.11), Web, and Exam systems
  • Permitted: Secure SSH (22) and HTTPS (443) network management to all Core & Edge switches
  • Protected by stateful inspection firewall on Edge router with MFA enforcement
ip access-list extended ACL-ADMIN-IN permit ip 10.20.0.0 0.0.0.255 any
