Architecture Evolution

Problem & Solution Matrix

How our redesigned architecture resolves legacy campus infrastructure bottlenecks, security vulnerabilities, and single points of failure.

Legacy Campus Problem Underlying Root Cause Our Engineering Fix
Slow Internet & Congestion
Single flat /16 network with uncontrolled broadcast domains, ARP storms, and no bandwidth prioritization.
Segmented 802.1Q VLANs + Dedicated Student /20 Subnet

Isolated broadcast domains, rate limiting, and prioritized QoS for critical ERP & Exam traffic.

Unauthorized Admin & Exam Access
Unrestricted inter-subnet routing allowed any student laptop to probe finance servers, ERP databases, and exam test banks.
Strict Zero-Trust ACLs & Air-Gapped Exam Zone

VLAN 50 (Exam) locked strictly to Exam-Server (10.70.0.12) with zero WAN access; Student VLAN blocked from Admin VLAN 20.

Frequent Campus-Wide Outages
Single core switch with no redundancy. Hardware reboots or link cuts immediately severed all campus services.
Dual-Core HSRP/VRRP & OSPF Multi-Area Redundancy

Active-Active dual core routers (Core1 & Core2) with virtual .1 gateways and sub-1.5s automatic failover.

IoT & Camera Cyberattacks
Unsecured IoT sensors and IP cameras connected directly to the open campus LAN, exposing them to botnet infections.
Isolated IoT / CCTV VLANs + AI Threat Telemetry

VLAN 60 cameras blocked from WAN; AI telemetry detects volumetric floods and port scans instantly.

Zero-Trust Hardening

Security Policies & Access Control Lists

Granular Layer 3/4 ACLs enforce least-privilege subnet isolation across student, faculty, IoT, and examination segments.

Student Wi-Fi (VLAN 30)

ACL-STUDENT-IN
  • PERMIT HTTP (80) & HTTPS (443) to Server VLAN (10.70.0.0/24)
  • PERMIT ICMP Ping to Server VLAN for diagnostic connectivity
  • PERMIT Outbound Internet access through Edge NAT router
  • DENY All internal access to VLAN 10 (Academic), 20 (Admin), 40 (IoT), 50 (Exam), 60 (CCTV) 
ip access-list extended ACL_STUDENTS
 permit tcp 10.30.0.0 0.0.15.255 10.70.0.0 0.0.0.255 eq 80 443
 permit icmp 10.30.0.0 0.0.15.255 10.70.0.0 0.0.0.255 echo
 deny ip 10.30.0.0 0.0.15.255 10.0.0.0 0.255.255.255
 permit ip 10.30.0.0 0.0.15.255 any

IoT Labs (VLAN 40)

ACL-IOT-IN
  • PERMIT HTTPS (443) & MQTT (8883) telemetry to Server VLAN
  • PERMIT Outbound Internet for cloud telemetry synchronization
  • DENY Direct lateral communication with Student, Admin, or Exam subnets 
ip access-list extended ACL_IOT
 permit tcp 10.40.0.0 0.0.0.255 10.70.0.0 0.0.0.255 eq 443 8883
 deny ip 10.40.0.0 0.0.0.255 10.0.0.0 0.255.255.255
 permit ip 10.40.0.0 0.0.0.255 any

CCTV / AI (VLAN 60)

AIR-GAPPED WAN
  • PERMIT RTSP / TCP streams to Campus NVR (10.70.0.15)
  • STRICT DENY All public Internet WAN access (zero camera botnet risk)
  • STRICT DENY All access to Student, Academic, and Admin subnets 
ip access-list extended ACL_CCTV
 permit ip 10.60.0.0 0.0.0.255 host 10.70.0.15
 deny ip any any

Online Exam (VLAN 50)

ZERO-TRUST EXAM
  • PERMIT HTTPS (443) exclusively to Exam-Server (10.70.0.12)
  • STRICT DENY All public Internet traffic (eliminates exam cheating/leaks)
  • STRICT DENY All other server, student, or admin subnets 
ip access-list extended ACL_ONLINE_EXAM
 permit tcp 10.50.0.0 0.0.0.255 host 10.70.0.12 eq 443
 deny ip any any

Admin & ERP (VLAN 20)

FULL ACCESS
  • PERMIT Full stateful inspection access to all internal VLANs and DC
  • PERMIT SSH (22) & HTTPS (443) management access to Core/Dist switches
  • PERMIT Full outbound Internet WAN access 
ip access-list extended ACL_ADMIN
 permit ip 10.20.0.0 0.0.0.255 any
99.99% Uptime

Reliability & High Availability Architecture

Dual Cisco Catalyst 3850 Core routers running HSRP active-standby gateway load sharing, OSPF Area 0 dynamic routing, and redundant 10 Gbps uplinks.

HSRP / VRRP Active-Standby Distribution

Shared virtual IP addresses ending in .1 ensure seamless client default gateway redundancy with <1.5s automatic failover.

Core1 Active VLANs

Active default gateway for VLAN 10 (Academic), 20 (Admin), 40 (IoT), 60 (CCTV) with HSRP Priority 110. Core2 stands by as backup (Priority 100).

Core2 Active VLANs

Active default gateway for VLAN 30 (Student Wi-Fi), 50 (Online Exam), 70 (Servers) with HSRP Priority 110. Core1 stands by as backup (Priority 100).

OSPF Area 0 Dynamic Routing

Non-blocking OSPF Area 0 over dual cross-chassis 10 Gbps fiber links ensures sub-second route reconvergence without STP broadcast blocking.
